## Significado de prioridad y esfuerzo

- **P0:** seguridad, regla crítica, validación obligatoria o dependencia fundacional.
- **P1:** función prioritaria o UI que completa el flujo.
- **P2:** mejora operativa que no sustituye controles críticos.
- **S/M/L:** tamaño estimado relativo a complejidad, **no compromiso de duración ni costo**.
