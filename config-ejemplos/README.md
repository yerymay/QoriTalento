# Configuración de desarrollo — ejemplos

Estos `.env.example` **solo enumeran variables propuestas**. No se ha creado backend ni frontend que las lean. Cuando se apruebe scaffold y el lugar de las variables, copiar el ejemplo a un `.env` local, completar claves fuera de Git y adaptar nombres a la implementación real.

No subir contraseñas, JWT/cookies, claves SMS/SMTP, CV de candidatos ni resultados de evaluación reales al repositorio. `OLLAMA_BASE_URL` apunta solo a loopback; nunca publicar `11434` directamente. Cualquier proxy o autenticación de servidor exige revisión de seguridad.
