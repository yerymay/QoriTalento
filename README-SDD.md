# Qori Talento · SDD integrado (Fases 1–5) · Base de desarrollo v1.0

Esta es la portada **vigente** de la documentación. Los README anteriores se guardan en `docs/historico/` porque fueron escritos cuando fases posteriores aún estaban pendientes.

## Estructura
- `docs/requirements/`: requisitos originales, auditoría, matrices de trazabilidad.
- `docs/decisions/`: decisiones expresamente aprobadas y registro de pendientes.
- `docs/architecture/`: arquitectura y especificaciones técnicas propuestas.
- `docs/implementation/`: backlog transversal, ola de ejecución, DoR/DoD, escenarios E2E y guía de arranque.
- `docs/historico/`: fuentes anteriores preservadas, no vigentes por defecto.
- `specs/`: 8 módulos con `spec.md`, `plan.md` y `tasks.md` (M06 incluye addendum IA).
- `contratos/`: OpenAPI 3.1 **borrador**.
- `diagramas/`: Mermaid del ER, arquitectura, reloj de examen y dependencias.
- `config-ejemplos/`, `herramientas/`, `ejemplos/`: material opcional de preparación local.

**Fuente vigente de comportamiento:** `spec.md` de la Fase 3, complementado por decisiones aprobadas y el addendum IA Fase 4. `plan.md` propone la arquitectura; `tasks.md` ordena su implementación. No declarar ninguna ADR ni bloqueo aprobados sin acta.

Para instrucciones ejecutables en Windows, abre [LEEME-PRIMERO.md](LEEME-PRIMERO.md) y [docs/implementation/00-arranque-tecnico.md](docs/implementation/00-arranque-tecnico.md).
