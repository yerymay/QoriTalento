# Qori Talento — Base de Desarrollo SDD

**Empieza aquí:** [LEEME-PRIMERO.md](LEEME-PRIMERO.md).

Este repositorio debe alojar el código del ATS en `frontend/` (Astro + Tailwind + Flowbite) y `backend/` (Node.js + Express), junto con los artefactos de especificación versionados. Base de datos objetivo: MySQL. Servicio local de IA para pruebas: Ollama con `qwen2.5:7b-instruct`.

**Estado actual del paquete:** documentación de las Fases 1–5 consolidada, **código funcional aún no entregado**. Las carpetas `frontend/` y `backend/` se integran o crean en la etapa de implementación; no se sobrescriben proyectos existentes.

**Ruta del backlog:** `docs/implementation/fase5-secuencia.md` y `specs/*/tasks.md`.
